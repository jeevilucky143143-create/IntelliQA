IntelliQA System Overview

IntelliQA is a complete, working, and polished academic Question Answering (QA) and Chatbot prototype built with Python Flask. The system combines Information Retrieval (IR) over unstructured text, structured Entity-Attribute-Value querying over SQLite/CSV, and multi-turn dialogue context management.

Academic Requirement Traceability Matrix

Requirement Implementation Details Source Location
1. IR-Based Factoid QA TF-IDF vectorization, Cosine Similarity, passage ranking, and sentence score extraction over text corpus. core/ir_engine.py & core/answer_extractor.py
2. Knowledge-Based QA Structured Entity-Attribute-Value query engine using SQLite database, Pandas CSV, and NetworkX Graph. core/knowledge_engine.py & database/knowledge.db
3. Dialogue Management Session-backed ConversationFrame state tracking entity coreference ("it", "its creator") across turns. core/dialogue_manager.py
4. Query Router Hybrid intent classification routing queries to Greetings, Knowledge Base, Dialogue Context, or IR engine. core/query_router.py
5. Answer Quality Evaluation Computes Exact Match (EM), Precision, Recall, F1 score, and confidence scores across benchmark dataset. core/evaluator.py & data/sample_questions.csv
6. Document Upload & Indexing Allows uploading .txt, .pdf, and .csv files with automatic real-time TF-IDF re-indexing. core/document_loader.py & routes/document_routes.py
7. Knowledge Graph Visualization Renders entity nodes, value nodes, and relationship edges using NetworkX and vis.js interactive graph. routes/knowledge_routes.py & templates/graph.html
8. Evaluation Dashboard Interactive evaluation view displaying performance metrics, Chart.js graphs, and detailed question breakdown. templates/evaluation.html & static/js/evaluation.js
9. Working Prototype Complete Flask web application running 100% locally without mandatory external API requirements. app.py

Technology Stack

Backend & Server

Python 3.9+, Flask 3.1, SQLite, Pandas, NumPy, scikit-learn (TF-IDF), NLTK, NetworkX, PyPDF.

Frontend & Design

HTML5, Modern Pastel CSS (#FAF8F5, #A8DADC, #CDB4DB, #FFC8DD, #FFE5B4, #BDE0C0), JavaScript, Chart.js, vis.js.

Testing & Benchmark

Pytest automated unit test suite, token-level F1/Precision/Recall metric calculators.
