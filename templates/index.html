Core QA Capabilities

IntelliQA automatically routes questions across three specialized engines

[ MODE 1 ]

IR-Based Factoid QA

Searches unstructured text documents (.txt, .pdf, .csv) using TF-IDF vectorization and Cosine Similarity to extract concise answers and supporting passages.

  • TF-IDF & Cosine Similarity
  • Passage Extraction & Ranking
  • Document Source Attribution
Manage Documents →
[ MODE 2 ]

Knowledge-Based QA

Queries structured Entity-Attribute-Value databases and CSV stores. Visualizes relationships via a dynamic NetworkX knowledge graph.

  • SQLite & Pandas CSV Engine
  • Entity & Attribute Detection
  • NetworkX Knowledge Graph
Explore Knowledge Base →
[ MODE 3 ]

Dialogue Manager

Maintains multi-turn conversation frames, tracking entity state and resolving contextual pronouns like "it", "its creator", or "that technology".

  • Session Conversation Frame
  • Coreference Resolution ("it", "that")
  • Small Talk & Chitchat Handler
